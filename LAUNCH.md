# Collection 01 launch notes

Gear5 UI provides five original React blocks and Folio 01, a complete portfolio
template. Use the component catalog to preview the interactions and the template
page to see the blocks working together.

Before publishing a release:
1. Run `pnpm verify` and `pnpm build`.
2. Check the deployed registry URLs and fresh installation.
3. Review desktop/mobile, keyboard, and reduced-motion behaviour.
4. Replace any real-site use of fictional sample content.
5. Record the results in CHANGELOG.md and keep HANDOFF.md current.

The root documentation now targets portfolios and product launches. Previous
general-purpose catalog screenshots and videos are retired.
